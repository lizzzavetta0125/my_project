# FinMate

Учёт личных финансов: доходы, расходы, бюджеты и отчёты.

**Стек:** Node.js, Express, HTML/CSS/JS, Material Design. Данные в `data/db.json`.

## Запуск

```bash
npm install
npm start
```

Открыть [http://localhost:3000](http://localhost:3000)

## Что умеет

- дашборд за месяц
- операции и категории
- лимиты бюджета
- отчёты по категориям / дням / типу
